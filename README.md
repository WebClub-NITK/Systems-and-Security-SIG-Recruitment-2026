# Systems-and-Security-SIG-Recruitment-2026
## Guidelines for submitting the tasks: 
- All tasks are equally valued for the interview selection.
- You need to work on at least one task for the interview.
- Completion of tasks is not the only criteria considered. Your effort and interest in learning the concepts are also considered.
- Feel free to submit any amount of work you have done on the tasks. Substantial but partially completed tasks are also accepted as submissions.
- The tasks need to be submitted through a github repository that must be kept private till the submission deadline. The mentors must be added to the repository as collaborators.
- You can contact the mentors of the tasks for any help. Some statements may be intentionally vague. Clarification with mentors would be necessary. 
- The interview will mainly cover theoretical questions about the domain of the chosen task as well as practical ones pertaining to the implementation of the task. 
- As you implement the task, make sure to develop a good overall understanding of the task domain. 
- For example: If you have chosen the Parallel Computing task, along with solving the task, understand the different constructs used in writing parallel programs, how to write basic parallelized versions of other serial programs, basics of threads and processes, etc.
- For a beginners roadmap to Systems, you can refer to our blog on the Web Club website at https://webclub.nitk.ac.in/blogs/3
- For more information on what Systems SIG does, you can see https://webclub.nitk.ac.in/blogs/14
